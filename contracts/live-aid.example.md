# Live Aid contracts (Markdown)

Human-facing BGM / handout lists live **inside** `sessions/<nnn>/live-aid.md` (see `trpg-live-aid`).

No separate `.yaml` run sheets. If an adapter needs JSON later, derive it from the MD tables at export time — do not make the GM maintain two formats.
