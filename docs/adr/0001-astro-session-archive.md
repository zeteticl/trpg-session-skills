# Astro for Session Archive generation

We need a static Session Archive that can later grow into a Campaign Hub, with bilingual UI copy. We accepted Markdown/MDX → Astro as the Archive Generator instead of framework-free HTML dumps or Obsidian/Quartz-as-primary, because content stays in the Campaign Vault while the Toolkit Repo owns the builder, and MDX/i18n scale better toward a Hub than one-off HTML scripts.
