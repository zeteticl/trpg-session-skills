# Toolkit Repo excludes runtime bots

This repository is a Keep-facing toolkit: agent skills, Archive Generator, asset scripts, Export Contracts, and Adapter Stubs. Running Discord/HKTRPG bots or hosted multi-tenant services stay out of tree so the MVP journey never depends on chat runtime, while contracts and stubs still document how external tools can consume Archive Manifest, BGM Cue lists, and Handout reveal payloads later.
