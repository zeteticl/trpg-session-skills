# Vault Layout

All skills operate on a **Vault Root** (path given by the GM or `TRPG_VAULT_ROOT`).

Formats: [formats.md](./formats.md) (Markdown by default). Site routes: [plan-alignment.md](./plan-alignment.md).

```
<vault>/
  INDEX.md
  modules/
    <module-id>/
      module.yaml                 # machine: id, system, locales
      source/
        scenario.zh-Hant.md
        scenario.en.md            # optional
      glossary.md                 # localize owns
      prep/                       # analyze owns → *.md
      assets/
        prompts/                  # handout-art → *.md
        portraits/
        backdrops/
        handouts/
        tokens/                   # token.png + token.json (machine)
      campaigns/
    <campaign-id>/
      campaign.yaml               # machine
      table-recruit.md            # table-recruit owns — Discord/open-table pitch
      pcs/
        <pc-id>.md
      hub/
        hub-manifest.yaml         # machine / regenerated by sync
        clue-board.md
      sessions/
        <nnn>/
          session.yaml            # machine
          notes.md
          transcript.md           # optional
          live-aid.md             # scenes + BGM + handouts (one MD)
          recap.md
          unresolved-clues.md
          keep-appendix.md        # NEVER published
          archive-manifest.yaml   # machine: publish contract
          media/
      modules-embedded/
```

## prep/ files

`00-overview.md` … `15-special-systems.md` — analyze owns (see `trpg-scenario-analyze` / charter §3).

`16-setting-remap.md` — **setting-reskin owns** (only on Module Variant folders).

`17-table-recruit.md` — optional module-level draft when no campaign yet (**table-recruit**); prefer `campaigns/<id>/table-recruit.md`.

## Module Variant

Forked as `modules/<parent-id>-<variant-label>/` by `trpg-setting-reskin`. Parent Module is not modified. `module.yaml` should include `derived_from` and `variant_label`.

## Embedded Module

Same package shape as `modules/<id>/`, under `campaigns/<id>/modules-embedded/<id>/`.
