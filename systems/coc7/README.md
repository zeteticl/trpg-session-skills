# CoC 7e System Pack

Unofficial vocabulary for Call of Cthulhu 7th Edition prep. Not a rules reprint.

## Extra analyze expectations

When writing `prep/12-system-nodes.md`, flag:

- Sanity (SAN) loss moments and suggested ranges (if stated in source; else mark unknown)
- Skill check gates that block investigation
- Combat or chase nodes
- Mythos exposure / tomes / artifacts
- Luck spends if the module calls for them
