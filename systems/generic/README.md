# Generic System Pack

System-agnostic labels for prep structure. Concrete rules packs override beat types and check vocabulary.

## Prep sections

Same file set as `docs/vault-layout.md` under `prep/`.

## Neutral terms

- **Beat**: a playable stretch of table time with a purpose.
- **Clue**: information that can move play when found or used.
- **Reveal**: moment a Handout or fact becomes player-facing.
